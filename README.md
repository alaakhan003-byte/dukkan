# دكّان — نظام المحل

موقع التطبيق + التطبيق نفسه + نسخة الحاسبة (ويندوز).

| المكان | شنو بيه |
|---|---|
| `public/index.html` | صفحة الموقع: تعريف، تثبيت للآيفون والأندرويد، وتنزيل نسخة الحاسبة |
| `public/app/` | التطبيق (يشتغل بدون إنترنت، ويتحدث لحاله كل ما ينفتح) |
| `src/shop.html` | ملف التطبيق الأصلي، نفس الملف اللي يشتغل داخل Claude |
| `src/site.js`, `src/sw.js`, `src/landing.html` | قوالب الموقع |
| `desktop/` | نسخة ويندوز (تفتح الموقع بنافذة خاصة) |
| `.github/workflows/desktop.yml` | يبني ملف `Dukkan-Setup.exe` على GitHub ويحطه بـ Releases |
| `build.py` | يبني `public/` من `src/` ويعطي رقم نسخة جديد |

## الربط (مرة وحدة)

### 1) GitHub
1. سوّي مستودع جديد (Repository)، مثلاً `dukkan`.
2. ارفع هذا المجلد كله عليه.

### 2) Cloudflare (Workers — الطريقة الجديدة)
1. **Workers & Pages → Create → Import a repository**، واختار `dukkan`.
2. Project name: `dukkan` · Build command: **فارغ** · Deploy command: `npx wrangler deploy` (الافتراضي).
3. **Deploy**. الرابط يطلع مثل `https://dukkan.<اسمك>.workers.dev`. ملف `wrangler.jsonc` يگول لـ Cloudflare يرفع مجلد `public`.

### 2-ب) أو Cloudflare Pages (الطريقة القديمة)
1. من Cloudflare: **Workers & Pages → Create → Pages → Connect to Git**، واختار المستودع.
2. الإعدادات:
   - Framework preset: **None**
   - Build command: `python3 build.py`
   - Build output directory: `public`
3. **Save and Deploy**. يطلع لك رابط مثل `https://dukkan.pages.dev`.

بعدها كل تحديث ينرفع على GitHub، Cloudflare ينشره لحاله خلال دقيقة، والتطبيق ياخذه أول ما ينفتح.

### 3) نسخة الحاسبة (EXE)
1. بـ GitHub: **Settings → Secrets and variables → Actions → Variables** → سوّي متغير `SITE_URL` وقيمته رابط Cloudflare (مثلاً `https://dukkan.pages.dev`).
2. شغّل `python3 build.py --repo اسمك/dukkan --url https://dukkan.pages.dev` وارفع التغيير (حتى زر التنزيل يأشر على مستودعك).
3. **Actions → نسخة الحاسبة (Windows EXE) → Run workflow**. بعد ~5 دقايق يطلع `Dukkan-Setup.exe` بـ Releases، وزر التنزيل بالموقع وبالإعدادات يشتغل.

نسخة الحاسبة فيها التطبيق كامل (تشتغل بدون إنترنت من أول مرة). تحديثات التطبيق توصلها من الموقع مباشرة: تنزل بس الملفات اللي تغيرت (حوالي 1 ميگا) ويطلعلهم «حدّث هسه» ويتحدث بثانية. EXE جديد ينبني بس لما يتغير مجلد `desktop/`. **لازم المستودع يكون Public** حتى أي واحد يگدر ينزّل ويحدّث.

## حسابات المحلات (السحابة)
- **لوحة المدير:** `/admin` على رابط موقعك. أول مرة تسوي بيها كلمة سر المدير (مرة وحدة)، وبعدها تسوي حساب لكل محل (اسم المحل، رقم صاحبه، كلمة سر).
- **صاحب المحل** يدخل من التطبيق برقمه وكلمة السر، ويبقى داخل على طول. يضيف عماله من الإعدادات ← العمال.
- **البيانات:** كل محل إله قاعدة بيانات خاصة بيه على Cloudflare (Durable Object)، ما أحد يشوف بيانات الثاني. التطبيق يحفظ على الجهاز أول (يشتغل بدون نت) ويرفع أول ما يرجع النت. إذا انحذف التطبيق أو تبدل الجهاز، يدخل برقمه وترجع كل البيانات.
- **السيرفر:** `worker/index.js`، والإعدادات بـ `wrangler.jsonc`.

## ملاحظات مهمة
- **بدون حساب** («جرّب على هذا الجهاز بس»): البيانات على الجهاز نفسه فقط. أول ما يدخل صاحب المحل بحساب، التطبيق يسأله يرفعها للسحابة.
- **الآيفون**: ثبّته من Safari ← مشاركة ← إضافة إلى الشاشة الرئيسية، وافتحه من الأيقونة. الآيفون ممكن يمسح بيانات المواقع اللي ما تنفتح فترة إذا ما مثبّتة.
- **الكاميرا**: بالموقع تفتح بث مباشر وتقرا الباركود لحالها. داخل Claude ما مسموح بث الكاميرا، فتصوّر صورة والتطبيق يقراها.
- **APK للأندرويد**: بعدين (يحتاج أداة بناء خاصة). هسه يتثبت من Chrome.
